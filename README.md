# improved-doodle
## A Film Script Repository

This repository contains "The Coding Journey" - a short film script about perseverance, community, and learning in the world of programming.

### Contents
- `film_script.md` - The complete screenplay for "The Coding Journey"

### About the Script
"The Coding Journey" is a 5-7 minute short film that tells the story of Maya, an aspiring programmer who learns that success comes not from avoiding mistakes, but from persistence and community support. Set in a modern coffee shop, the script explores themes of learning, mentorship, and the collaborative nature of programming.

### Script Format
The screenplay follows standard industry formatting with:
- Scene headings (INT./EXT. locations)
- Character names in caps
- Dialogue and action lines
- Production notes and technical requirements

Perfect for film students, indie filmmakers, or anyone interested in stories about the coding community.
